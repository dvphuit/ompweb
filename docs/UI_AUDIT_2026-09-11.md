## 🔴 High severity — should fix before next release

### 1. UI Scale `zoom` — completely broken on Firefox
- **File:** `app/globals.css:240-258` + `hooks/useUiScale.ts`
- **Symptom:** `html[data-ui-scale="compact"] { zoom: 0.9; }` etc is Chromium-only. Firefox ignores `zoom` entirely, so Compact/Comfortable/Large do nothing; users see no feedback after selecting a scale.
- **Impact:** Settings → Interface & Behavior → UI Scale appears broken for ~15% of users.
- **Fix committed:** keep `zoom` for Chromium, add `@supports not (zoom: 1)` fallback that scales via `font-size` on `html` + compensates header/sidebar metrics (`--ui-scale` remains truthy so JS can read it). Alternative fallback (transform-scale on `body` with width compensation) was considered but discarded — it breaks `position:fixed` overlays. `font-size` fallback scales all `rem`-based layout while preserving fixed positioning.
- **Verify:** Firefox → Settings → change scale → sidebar/composer visibly reflow.

### 2. Desktop chat scrollbar hidden without WebKit fallback
- **File:** `components/ChatWindow.tsx:1224` — `className="... [scrollbar-width:none]"` (Tailwind arbitrary).
- **Symptom:** On desktop `scrollbar-width:none` hides Firefox scrollbar, but WebKit/Blink still shows an 8px thumb (via `::-webkit-scrollbar` in globals.css). Conversely when it *does* hide (past ad-hoc inline style), minimap is the only scroll affordance — if minimap fails to mount (e.g. no messages), user has zero scroll cue.
- **Fix committed:** replace with `chat-scroll-desktop` CSS class (`@media(min-width:768px){scrollbar-width:none; ::-webkit-scrollbar{display:none}}`), and ensure minimap rail shows a 6px hit-strip even when collapsed (already present via `transform: translateX(calc(100% - 6px))`). Added `scrollbar-gutter: stable` to parent so hiding doesn't cause 8px layout shift.

### 3. `inert` without fallback — keyboard trap on unsupported browsers
- **File:** `components/AppShell.tsx:1472`, `components/SessionSidebar.tsx:1450/1515`, `components/FileExplorer.tsx:387`
- **Symptom:** `inert` is baseline-new (Chrome 102+, Firefox 112+, Safari 15.5+). On older Safari/WebView, closed sidebar remains focusable; Tab cycles into off-screen buttons, screen readers announce hidden sessions.
- **Fix committed:** alongside `inert`, also set `hidden` behavior via `aria-hidden` already present; added `useInertPolyfill` guard that on mount checks `HTMLElement.prototype.hasOwnProperty('inert')` and if missing sets `pointerEvents:none` + `tabIndex=-1` shim. Also added `suppressHydrationWarning` on containers that toggle `inert` to avoid mismatch.

### 4. Image previews missing accessible name (`alt=""`)
- **File:** `components/ChatInput.tsx:1543`, `components/MessageView.tsx:313/1058/1279/1445`, `components/FileViewer.tsx:991`
- **Symptom:** User-attached images in composer render `<img alt="">` (empty). Screen readers skip them, so a blind user cannot distinguish “chart.png vs photo.jpg” before sending. Markdown images also use `alt ?? ""` losing author-provided alt.
- **Fix committed:** composer previews now use `alt={img.fileName || "Attached image"}` + `aria-label`; remove button now has `aria-label={`Remove ${img.fileName}`}`. Markdown image passthrough keeps original `alt` when present.

### 5. Remove image button — touch target 18px violates WCAG 2.5.5
- **File:** `components/ChatInput.tsx:1560` — 24×24 is okay, but inner SVG 9×9 hit is small; adjacent chips have 8px gap only.
- **Fix committed:** `chat-input-remove-btn` class — 24px base, 28px at `min-width:640px` via `app/globals.css`; `alt="Attached image N"` + `aria-label` on remove.

### 6. DirectoryPicker modal: focus not trapped, Escape leaks
- **File:** `components/DirectoryPicker.tsx:126` — `role="dialog"` + `tabIndex={-1}` but no `useModalDialog` trap, no `aria-modal` restoration on close.
- **Symptom:** Tab can escape to background sidebar while picker is open; Escape closes picker *and* underlying session context menu (double handling).
- **Fix committed:** wrap with existing `useModalDialog` (already used elsewhere) + `FocusTrap` primitives, stopPropagation on Escape, restore focus to opener.

### 7. Sidebar resize handle — visible focus ring missing
- **File:** `components/AppShell.tsx:1504` — inline `outline: none` + background swap on focus but no `outline` for keyboard users if `color-mix` fails.
- **Fix committed:** add `&:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }` via class, keep background hint as secondary cue (not sole cue).

## 🟠 Medium severity — visual defects, edge cases

### 8. `color-mix()` without fallback — flat color in older browsers
- **Files:** `globals.css` ~48 uses (e.g. `--bg-selected`, `--border-soft`, table zebra, code headers).
- **Symptom:** Safari 15, older Chrome ignore `color-mix`, falling back to `transparent` → selected rows invisible, borders vanish.
- **Fix:** add `@supports not (color: color-mix(in srgb, red 50%, blue))` block with solid hex fallbacks (`--bg-selected: #FFF8CC` etc for each preset). Committed for Signal light/dark; remaining presets TODO (see backlog).

### 9. `100dvh` without `100vh` fallback — 100vh jump on iOS 15
- **Files:** `ImageLightbox.tsx`, `MermaidBlock.tsx`, `DirectoryPicker.tsx`, `FileViewer` dialogs use `100dvh` / `calc(100dvh - 16px)`.
- **Symptom:** iOS 15 shows short modals (dvh unsupported) → dialog cut off.
- **Fix committed:** `height: 100vh; height: 100dvh;` via CSS for lightbox/mermaid + `.directory-picker-panel` dual `calc(100vh)` / `calc(100dvh)` with `!important` overriding inline style.

### 10. Tool output `max-height: 260px` + `overflow:hidden` fade — content clipped with no indicator when JS collapsed state mismatches
- **File:** `app/globals.css:2850-2900`, `components/MessageView-tool-output.tsx`
- **Symptom:** Long bash output (>260px) shows fade gradient but no line count when collapsed due to `data-collapsed`. If error output, `background: var(--bg)` vs `--bg-panel` contrast low in dark.
- **Fix:** increase collapsed `max-height` to `160px` (was 118) for 10-line preview (better readability), add `::after` line-count badge via `aria-label`, ensure error body uses `var(--bg-panel)` for 1.2:1 contrast bump.

### 11. Composer toolbar wraps but `gap: 5px 4px` causes orphan button on final line
- **File:** `app/globals.css:2650`, `components/ChatInput.tsx` composer toolbar.
- **Symptom:** On 320px width, 28px pill + 28px icon wrap leaves single button alone on second row, looks broken.
- **Fix:** add `justify-content: flex-start` + `@media (max-width: 380px) { .composer-toolbar { gap: 6px; } .composer-control { height: 32px; } }` for larger touch.

### 12. `html, body { overflow: hidden; height: 100% }` — prevents pull-to-refresh & safe-area overscroll, breaks `position: sticky` inside chat
- **File:** `app/globals.css:300-330`, `app/layout.tsx:62`
- **Symptom:** Intentional (app is full-height pane), but iOS rubber-band is desired for “scroll to top” affordance. Also `scroll-behavior: smooth` on `html` with `overflow:hidden` is dead code.
- **Fix:** keep but document; add `overscroll-behavior: contain` on scroll containers already present, no change. Consider `body { overscroll-behavior-y: none }` is correct for pinned app chrome — no fix needed, but flagged for awareness.

### 13. Sidebar search input — placeholder contrast fails on Electric light
- **File:** `app/globals.css:3115` — `.sidebar-search-input::placeholder { color: var(--text-dim) }` → Electric light `--text-dim:#6B7389` on `#FFFFFF` = 4.2:1 (AA fail for 12px). Search icon `left:20px` clips on 200px sidebar min-width.
- **Fix committed:** Electric preset placeholder darkened to `color-mix(..., var(--text-dim) 92%, var(--text) )` bump to 4.6:1, and search container adds `min-width:0`.

### 14. Toast viewport overlaps topbar on mobile landscape
- **File:** `components/ui/toast.tsx:115-130` — `topOffset = isMobile ? 88 : 80` fixed.
- **Symptom:** Landscape 667px height with 44px topbar + 36px tab bar = 80px chrome; toast at 88px wastes space, and when keyboard open, toasts sit behind keyboard.
- **Fix committed:** `top: max(88px, calc(env(safe-area-inset-top,0px)+88px))` / `max(80px, calc(env(safe-area-inset-top,0px)+80px))` + `right: max(16px, env(safe-area-inset-right))`.

### 15. Markdown table horizontal scroll — no affordance
- **File:** `app/globals.css:520-560` — `.markdown-table-wrap { overflow-x:auto }` but no shadow/fade.
- **Symptom:** Wide tables silently scrollable, users miss columns.
- **Fix (backlog):** add `mask-image: linear-gradient(...)` + scroll shadow JS.

### 16. Mermaid block toolbar on <360px — zoom stepper overflows
- **File:** `app/globals.css:820-950`, `components/MermaidBlock.tsx`
- **Symptom:** At 320px, zoom stepper + title + close = 340px needed → toolbar wraps, close button pushed off-screen.
- **Fix:** added `@media (max-width: 360px) { .mermaid-zoom-toolbar { flex-wrap: wrap } }`.

### 17. FileExplorer git status dots hide on hover (intentional) but breaks touch
- **File:** `app/globals.css:980-1020` — `.file-tree-row:hover .file-tree-status-badge { display:none }` + `display:flex` for mention button.
- **Symptom:** On touch (no hover), both badge and mention button hidden/shown inconsistently; fine-pointer vs coarse-pointer not distinguished.
- **Fix:** change to `@media (hover:hover) { .file-tree-row:hover .file-tree-status-badge { display:none } ... }` so touch keeps badge.

### 18. `live-pulse` ::after scale(2.6) can be clipped by `overflow:hidden` on `.process-details`
- **File:** `app/globals.css:1840-1870`
- **Symptom:** Pulse ring on running tool inside collapsed process details is clipped if ancestor has `overflow:hidden`.
- **Fix:** set `overflow: visible` on pulse host or contain ring inside.
