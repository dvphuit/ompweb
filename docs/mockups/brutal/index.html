All three issues fixed and verified on the live app:

Minimize / Maximize / Close were dead buttons

Root cause: the top bar is a window-drag region (-webkit-app-region: drag) and the min/max/close cluster sat outside the no-drag exemption — so every click was swallowed by window-dragging. Added .topbar__window-controls to the no-drag rule. Verified live: clicking Minimize → OS reports iconic=True.
